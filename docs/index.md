# SMS Toolbox

Back up your SMS to your own Gmail and restore them on any phone. The GitHub build
also forwards messages that match your rules and sends messages on a schedule.

- **[Get it on Google Play](https://play.google.com/store/apps/details?id=com.neteinstein.smsredirect)**: Backup and Restore.
- **[Download the APK from GitHub](https://github.com/neteinstein/SMS-Redirect/releases/latest)**: every feature, with in-app updates.
  First time installing an APK? **[Follow the step-by-step guide](install-apk.md)**.
